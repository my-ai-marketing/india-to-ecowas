# India → ECOWAS FMCG Processing Feasibility Study

Static GitHub Pages feasibility-study dashboard for a proposed 1,000 sqm Indian vegetable processing/dehydration unit exporting to ECOWAS markets.

## Base planning model
- 5 tonnes/day fresh vegetable input
- 26 operating days/month
- 130 tonnes/month fresh input
- 12% blended dehydration yield for the base model
- Product basket: mushroom, green beans, carrots, green onions, corn and green pepper
- Location comparison: Surat/Hazira, Tuticorin port-side, and Dindigul/Madurai → Tuticorin

## Currency
The underlying cost model is INR. USD equivalents are calculated in `app.js` from the editable study FX assumption. Default snapshot: US$1 = INR 95.89 on 17 Sep 2026.

## Important
This is a planning feasibility study, not a bankable DPR. Assumptions should be replaced by written supplier, machinery-vendor, transporter, shipping-line and buyer quotations before investment approval.
